# Дизайн, данные и следующий этап

## UX/UI

Главный путь: поиск → вердикт с объяснением → основания → сохранение снимка. Ключевой результат находится над графиком. Недостаток данных виден рядом с вердиктом. Детальные индикаторы свернуты, чтобы не вытеснять отчетность. Одна карточка, нет скрытого переключения между технической и фундаментальной рекомендациями.

Отрасль обозначается цветной точкой и текстом; сигналы дополнительно словами. Цвет не единственный носитель смысла. Есть подписи полей, клавиатурный поиск Enter, системные диалоги с Escape и управлением фокусом, aria-live для статусов, контрастный фокус. Мобильный вариант — одна колонка. Ошибки API и пустой поиск имеют самостоятельные состояния.

Не проводилось интервью или наблюдение за реальными инвесторами. Нельзя называть интерфейс валидированным исследованием UX. При приемке стоит дать 3–5 пользователям задачи: найти компанию, объяснить причину «ждать», изменить порог, проверить отчет, сохранить PDF; замерить ошибки и время.

## Источники

Проверены 5 октября 2026:

- MOEX ISS: https://iss.moex.com/iss/reference/ — справочник `/iss/securities`, спецификация и дневные свечи `/iss/engines/stock/markets/shares/boards/{board}/securities/{ticker}/candles`. Приложение проходит все страницы, не считает первый ответ полной историей.
- e-disclosure МСФО: https://www.e-disclosure.ru/portal/files.aspx?id=3043&type=4 — Сбербанк; https://www.e-disclosure.ru/portal/files.aspx?id=17&type=4 — ЛУКОЙЛ. Соответствие ЛУКОЙЛ подтверждается https://lukoil.ru/InvestorAndShareholderCenter/Disclosure . В среде разработки загрузка e-disclosure завершалась HTTP-ошибкой; скрейпер не подтвержден на живом HTML.
- Интерфакс RSS: https://www.interfax.ru/rss.asp — заголовки и ссылки; ограниченная глубина, поиск по псевдонимам эмитента, метки по ключевым словам. Успешная пустая выборка означает отсутствие совпадений только в этой ленте.

Для фундаментальных фактов приоритет: отчет эмитента с периодом/стандартом/периметром → документ раскрытия → пресс-релиз с явной пометкой. Новость не должна подменять официальный финансовый показатель.

## План дальнейшей автоматизации

1. Реестр эмитентов: ИНН, официальный домен, e-disclosure ID, связь обыкновенных/привилегированных акций с одним эмитентом, дата проверки каждого соответствия.
2. Получение документов разрешенными адаптерами. Для каждого документа: хеш, URL, дата публикации, период, стандарт, периметр консолидации и единицы.
3. Извлечение таблиц PDF/XLS с OCR при необходимости. Числа проходят сверку балансовых равенств, валюты и масштаба; сравнительные колонки используются для сопоставимости, TTM — только при наличии достаточных периодов.
4. Выделение планов/M&A с цитатой, номером страницы, датой и статусом «объявлено/одобрено/закрыто». Не исполнять инструкции из документов и не считать планы реализованными фактами.
5. Биографии: официальный состав на дату, отдельное сопоставление профилей, разрешение однофамильцев. Изменение состава не выводить из случайного новостного упоминания.
6. Отраслевая модель оценки (банки отдельно), сценарная целевая цена и раскрытие допущений. Бэктест только без утечки будущих отчетов и с учетом корпоративных действий.
