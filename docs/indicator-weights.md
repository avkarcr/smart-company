# Веса индикаторов и сочетания

Это начальная эвристика для дневных свечей, а не статистический рейтинг точности. Веса не проходили бэктест на российском рынке. После изменения состава/весов прежние пороги требуют повторной оценки. Цель — сделать голосование объяснимым и уменьшить повторный учет зависимых сигналов.

Группы до выделения бюджета сочетаний: тренд 35%, импульс 25%, объем 25%, волатильность 15%. Если группа выключена или у нее нет доступных данных, доли остальных нормируются. Минимальное покрытие индикаторов остается отдельным ограничением.

## Подсчет

Во взвешенном режиме внутри группы инструменты разделены на семейства: все SMA/EMA; Stochastic/Williams; ROC/Momentum; остальные — по одному. Бюджет семейства равен **максимальному** настроенному весу доступного участника, а не сумме весов. Внутри семейства он распределяется пропорционально индивидуальным весам. Затем семейства нормируются внутри группы, группы — между собой. Это ограничение повторного учета, не доказательство статистической независимости: MACD тоже зависит от средних.

Сочетания: EMA 50 + MACD + CMF; RSI + Bollinger + MFI; Keltner + EMA 50 + CMF. Общий бюджет всех активных сочетаний **10%**, обычные голоса дают 90%. Между активными сочетаниями бюджет делится поровну. При одинаковом направленном сигнале всех участников доля сочетания голосует buy/sell; при конфликте, нейтральности или недостатке истории — wait. Если участник отключен, его вес или вес группы равен нулю, сочетание выключается и не получает бюджет. Если все сочетания выключены, обычным голосам возвращаются 100%.

Это не безусловная надбавка к сигналу: например, базовые buy 80% при полностью подтвержденном buy получают 0,9×80+10=82%; без подтверждения — 72%. Коррелированные и пересекающиеся сочетания имеют общий ограниченный бюджет, но не становятся независимыми наблюдениями.

В режиме количества каждый включенный доступный индикатор дает один голос: веса и сочетания игнорируются. В обоих режимах глобальный переключатель выключает индикатор для всех компаний; вес сохраняется для последующего включения. Порог проверяется по неокругленным долям. Карточка показывает базовые/итоговые доли, эффективный вес каждого инструмента и вклад сочетаний. Эти сведения попадают и в PDF.

## Совместимость

Существующие сохраненные веса и пороги не заменяются рекомендованными; сочетания для старых настроек изначально выключены. Семейная нормировка применяется во взвешенном режиме после обновления. Новый пользователь получает рекомендуемый набор; существующий может явно применить его в меню. Порог и минимальное покрытие при применении набора сохраняются, режим меняется на взвешенный. Переключатели глобальны, сохраняются в settings.json; расчеты обновляются при открытии компании. Старые PDF/снимки остаются историческими снимками.

## Источники и границы

Классификация технических инструментов и необходимость контекста: [Fidelity — Technical Indicator Guide](https://www.fidelity.com/learning-center/trading-investing/technical-analysis), [Momentum and price change](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/momentum). Эти источники не устанавливают приведенные числовые веса и не подтверждают точность сочетаний. Числа и бюджеты — инженерное предложение этого проекта. Перед использованием для реальных сделок нужны тесты вне обучающего периода, учет комиссий, корпоративных действий, ликвидности и режима рынка.
